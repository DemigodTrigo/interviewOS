# InterviewOS

AI-powered interview preparation and resume optimization platform with ATS analysis, AI mock interviews, multi-agent workflows, and automation pipelines.

---

# Features

- AI Resume Analyzer
- ATS Score Checker
- AI Interview Questions
- Mock Interview Simulator
- Career Roadmap Generator
- Job Tracker
- AI Feedback System
- Multi-Agent AI Workflows
