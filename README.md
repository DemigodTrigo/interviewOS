# InterviewOS 🚀

AI-powered interview preparation and career growth platform built with React, TypeScript, Supabase, and Generative AI.

---

## 🌟 Features

- 🤖 AI Mock Interviews
- 📄 ATS Resume Analyzer
- 🎤 Voice-based Interview Simulation
- 💼 AI Career Coach
- 🔐 Authentication & Protected Routes
- 📊 SaaS-style Dashboard
- ⚡ Real-time AI Feedback
- ☁️ Cloud Deployment with Vercel

---

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- TanStack Router
- Vite
- Tailwind CSS

### Backend & Services
- Supabase
- PostgreSQL
- Authentication

### AI Integrations
- Groq AI API
- Prompt Engineering
- Speech Recognition API

### Deployment
- Vercel

```env

VITE_GROQ_API_KEY=your_groq_api_key


📦 Installation
git clone https://github.com/DemigodTrigo/interviewOS.git

npm install

npm run dev


🏗️ Production Build
