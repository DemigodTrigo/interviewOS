# InterviewOS 🚀

AI-powered interview preparation and career growth platform built with React, TypeScript, Supabase, and Generative AI.

---

## 🌟 Features

- 🤖 AI Mock Interviews
- 📄 ATS Resume Analyzer
- 🎤 Voice-based Interview Simulation
- 💼 AI Career Coach
- 🔐 Authentication & Protected Routes
- 📊 SaaS-style Dashboard
- ⚡ Real-time AI Feedback
- ☁️ Cloud Deployment with Vercel
